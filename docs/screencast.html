▹ one rule

Code review that
proves every finding.

No finding reaches a human until a second agent has tried to disprove it — by running the code — and failed.
the problem

AI review bots cry wolf.

They spray plausible comments that are mostly wrong, so engineers learn to ignore them. CI catches what tests cover — humans catch what tests miss.
The job isn't “find more issues.” It's “only tell me things that are true, with evidence.”
